      How the safety check works

      Each model loads with modelFitPolicy: 'refuse'. It blocks a definite failure from a supported fitter. An unknown probe can still load. Free memory can change after an assessment.

      The app reads the engine's fit details, including device memory when available, then releases every model it loaded.

      Reading your result

      Likely fits is an advisory memory check. It reserves no memory and predicts no speed. Unknown means the evidence cannot support a fit claim.

      Disk size describes model files. RAM is the memory a running model needs. A computed floor is a lower bound that omits unmeasured costs.

      Device projections appear only when an explicit load test returns them. Missing fields stay unreported.
